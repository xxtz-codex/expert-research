# 其他 AI 助手安装指南（Kimi / 通义 / 智谱 / 讯飞星火 / 文心一言 等）

这些助手不支持技能文件夹，统一用**系统提示 / 角色设定 / 自定义指令**粘贴浓缩版。原理一样：把浓缩指令全文粘贴到该平台的"系统提示词 / 角色 / 人设"设置里。

## 通用步骤

1. 打开对应应用/网页 → 设置 → 找到 **系统提示词 / 角色设定 / 自定义指令 / 人设**（不同平台叫法不同）
2. 粘贴 [`instructions/compact-zh.txt`](../instructions/compact-zh.txt) 全文（英文场景用 `compact-en.txt`）
3. 保存 → 新会话生效

## 常见平台入口

| 平台 | 设置入口（大致） |
|---|---|
| Kimi（月之暗面） | 设置 → 通用 → 自定义回复设置 / 快捷指令 |
| 通义千问 | 设置 → 个性化 → 系统提示词 |
| 智谱清言（GLM） | 设置 → 角色与偏好 → 自定义人设 |
| 讯飞星火 | 设置 → 通用设置 → 人设与回复 |
| 文心一言 | 设置 → 偏好设置 → 系统指令 |
| 腾讯元宝 | 设置 → 自定义指令 |
| 字节跳动（豆包） | 见 [doubao.md](doubao.md)（支持技能文件夹完整版） |

> 入口名称各平台会更新，找不到时搜索该平台文档"系统提示词/自定义指令"即可。

## 验证

任意新会话输入：`用模板 2 帮我规划学习 Python 的路线`，按专家五段式输出即成功。

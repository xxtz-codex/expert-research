# Claude.ai 安装指南

Claude.ai（网页版）不支持技能文件夹，通过 **Project 说明（Instructions）** 粘贴浓缩指令版。

## 安装

1. 打开 claude.ai → 创建/打开一个 **Project**
2. 进入 Project 设置 → **Project instructions / 项目说明**
3. 粘贴 [`instructions/compact-zh.txt`](../instructions/compact-zh.txt) 全文（英文场景用 `compact-en.txt`）
4. 保存

## 验证

在项目会话中输入调研类问题，如"用模板 3 帮我分析某产品的竞品"，按专家模板执行即成功。

## 备注

- Claude.ai 同样支持 **Projects 的 Knowledge** 上传文件——可上传 `SKILL.md` 作为参考资料增强命中
- Claude Code（本地 CLI）用户请走 [claude-code.md](claude-code.md) 的完整版安装

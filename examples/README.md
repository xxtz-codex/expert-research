# 使用示例（Examples）

以下 3 个示例展示本技能的实际用法与预期输出结构。你可以直接在支持本技能的 AI 中复制使用。

---

## 示例 1 · 工具选型（模板 1）

```
请以技术选型专家的标准，帮我找 Obsidian 的同类/替代品并给出选型建议。
要求：本地存储优先、免费或开源、Windows 可用。
```

**预期输出结构**：
1. 候选总览表（8-10 个：Logseq / Typora / Notion / Joplin / SiYuan 思源 / Trilium / Obsidian…），每条含来源链接 + ✅/⚠️/❌
2. 深评对比表：候选 | 存储方式 | 免费性 | 双向链接 | 插件生态 | 隐私 | 许可证
3. 推荐路径：最佳整体 / 最轻量 / 最强大，各附代价
4. 风险清单：数据锁定（是否 Markdown）、免费转付费历史、维护状态

**专家隐性维度会覆盖**：数据锁定（是否纯 Markdown 可迁移）、开源协议传染性、插件权限、免费层锁客路径、供应链单点等。

## 示例 2 · 旅行规划（模板 9）

```
请以资深旅行规划师的标准，帮我规划一次 5 天重庆→成都的旅行。
预算 3000 元，情侣出行，节奏偏休闲。
```

**预期输出结构**：
1. 需求澄清表（天数/预算/同行人/节奏）
2. 行程总览表：日期 | 城市 | 主题 | 交通 | 住宿区域
3. 逐日详表：时段 | 安排 | 预约需求 | 备选方案
4. 预算表：交通/住宿/门票/餐饮/购物 + 可砍项
5. 行前清单：证件/预订/保险/紧急电话

**专家隐性维度会覆盖**：旺季人潮与预订时间、景区内交通隐性成本、民宿 vs 酒店的真实差价、雨天备选、行程留白等。

## 示例 3 · 投资理财框架（模板 10）

```
请以理财规划顾问的标准（合规、不构成投资建议），帮我做 10 万块钱 3 年期理财规划。
只给配置框架，不要推荐具体个股或产品代码。
```

**预期输出结构**：
1. 财务状况表（收入/支出/可投资额）
2. 风险测评结论（风险等级 + 依据）
3. 配置框架：资产类别 | 比例 | 工具类型 | 风险等级 | 流动性
4. 避坑清单（高息骗局识别、追涨杀跌、费率吞噬）
5. 末尾强制声明：不构成投资建议，市场有风险

**质量红线**：不荐具体标的、历史业绩标注≠未来收益、任何"保本高收益"按诈骗特征标注。
